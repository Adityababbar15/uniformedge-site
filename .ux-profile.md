# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Hairline 1px borders on every raised surface, shadows under 0.08 alpha, one crimson accent for interactive elements, navy and ivory surfaces. Fraunces for headings, Inter for body. The running stitch is the site's single graphic motif (hero, timeline rule, closing band) — do not add a second one. Motion is deliberately more visible than the 100/150/200/300ms tokens, at the owner's request: scroll reveals 700ms with 28px travel, the stitch 900ms, the hero opening sequence up to 1.8s (played once on load). Everything is transform/opacity only and is made instant under reduced motion. Documented here as an optical exception.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders (photo scrims that protect text contrast are not decoration)
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Text 4.5:1, large text and borders 3:1. Button text on crimson uses `crimson-600` (white on `crimson-500` is only 4.23:1).
- **Touch / focus:** 44×44px hit targets, visible focus rings, Escape closes overlays and returns focus to the trigger. Honour `prefers-reduced-motion`.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain and specific. Errors say what to add, never what the visitor did wrong. Never state anything unverified — no invented clients, statistics, awards, certifications or testimonials; mark placeholders clearly. Proper nouns keep their capitals (UniformEdge, Neeraj School Uniforms, WhatsApp).

## Icon library

- **Library:** Project SVG
- **Package / path:** `components/graphics/Icons.tsx`
- **Notes:** One set only. 24px grid, 1.5px stroke, round caps and joins, no fills, `aria-hidden` (decorative). New icons follow the same rules. No emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
