# UniformEdge — logo master files

Rebuilt as vector from the brand sheet reference. Navy `#0F2A4D`, crimson `#E53935`.
Wordmark is **outlined** (Jost, SIL OFL) — no live text, nothing re-flows without the font.

Open `specimen-sheet.html` in a browser for the full system with rules.

## svg/ — the masters (18 files)
6 variants × 3 treatments (full colour, `-black`, `-white`):

| Variant | Use |
|---|---|
| `primary-lockup` | Default: websites, letterheads, invoices |
| `lockup-with-tagline` | Catalogue cover, presentations. Needs 70 mm |
| `stacked` | Narrow columns, square placements, packaging |
| `wordmark-only` | Where the icon already appears on the surface |
| `icon` | Profile pictures, tags. Fits an 80% circular safe zone |
| `favicon-mark` | 16–32 px only. E dropped — it cannot survive |

## png/ — 11 exports
Transparent (RGBA) for icons and the email signature; navy for social banners.
See section 06 of the specimen sheet for what each is for.

## pdf/ — 6 vector PDFs
For print vendors. Vector throughout — no embedded raster.

## Regenerating
Everything derives from `svg/`. Never regenerate an asset from a PNG.
