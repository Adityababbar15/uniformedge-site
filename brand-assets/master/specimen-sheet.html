02

Colour

Two brand colours and one neutral. The primary mark never uses more than three colours, and there are no gradients in any master.

Navy — #0F2A4D

rgb(15, 42, 77) · Pantone 289 C
The uniform colour itself. Institutional, and it prints reliably on cartons and woven labels where a lighter blue drifts.

Crimson — #E53935

rgb(229, 57, 53) · Pantone Red 032 C
The edge. One accent, used once per surface, so it still reads as emphasis rather than decoration.

Mist — #F2F5F8

rgb(242, 245, 248) · Pantone Cool Gray 1 C
Neutral ground for catalogue pages and web sections. Cooled slightly toward the navy so it never reads as dirty white.

03

Typography

Jost, licensed under the SIL Open Font License — free for print, web, packaging and embroidery with no per-seat cost, which matters when a school's own print vendor needs the file. Jost Regular (400) sets “Uniform”; Jost Bold Italic (700) sets “Edge”; Jost Medium (500), letterspaced 0.20 em, sets the tagline. All three are converted to outlines in the masters — the font is only needed if you re-set the wordmark, which you should not do.

04

Clear space

Keep clear space equal to the height of the letter U in the wordmark on all four sides. It is measurable on any rendition at any scale, with no reference to the original artboard. The dashed rule below shows it at the correct ratio.

07

Five things never to do

Don't recolour it

No per-school palettes, no gradients, no tints. Navy and red, or one flat ink.

Don't distort it

The slant on the E is already the angle. Never stretch, squash, or add rotation.

Don't add effects

No shadows, outlines, bevels or glows. An embroidery digitiser cannot read them.

UniformEdge
Don't re-typeset it

Never set the name in another font to fake the wordmark. Use the supplied file.

Don't crowd it

Nothing enters the clear space — no rules, page numbers, school crests or captions.
